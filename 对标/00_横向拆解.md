## 二、先纠正我上一轮的一个错误

上一轮我说「每张图停留 29 秒，图片数 = 时长 ÷ 29」。

**这个结论下得太早了。** 当时只有 3 个样本，其中 2 个来自同一个账号（每天读书），本质上是同一个人的剪辑习惯。

加上这三条之后，节奏区间是 **5 秒到 29 秒，差 6 倍**：

- 晚禾书语：5–7 秒一换，快的像翻卡片
- 麦麦陪你读书：15–20 秒一段
- 每天读书：29 秒一张
- 叔本华：整片一张

**所以「每张图几秒」不是行业标准，是账号自己的风格。** 别抄别人的秒数，抄不来。

## 三、真正稳定的三条规律

八条视频里，这三条没有一条例外：

**1. 顶部有固定的主题条。**  
除了图集和单图型，其余全部在画面顶部压一条固定的文字：《优雅老去》：老了一定要谈恋爱 / 《中国人的家风》余世存·著 / 《屏蔽力》扎米医生·著 / 加缪：人这一辈子……

它每 2–5 秒就重复出现一次。观众滑走又滑回来，永远知道这条在讲什么。这是完播率的关键——比任何钩子都管用。

**2. 字幕永远在同一个位置，白字黑边。**  
位置从 78.5%（叔本华）到底部黑边（麦麦），但都在 UI 安全区内，且从不移动。位置固定，眼睛才不用找。

**3. 画面是「配图」，不是「作品」。**  
八条里**没有一条用了转场特效、运镜、缩放、滤镜动画**。全是硬切：图出现、停住、切走。

这条最反直觉。很多人做视频觉得要加转场、加动效、加 Ken Burns，实际上爆款的做法是最朴素的——换图、换字、换图、换字。

> 顺带说：你 erchuang 里的 zoompan 微动（1.0→1.05）其实属于"多余动作"。这八条对标一条都没用。省掉它能减少一半渲染开销。

## 四、五种形态的完整规格

### 形态 A · 单图（叔本华）

- 1080×1624（2:3），28.4s，**1 张 AI 油画肖像**
- 无标题条、无模板、无运镜
- 字幕居中，中心在 78.5% 高度，单行 ≤13 字，白字黑边
- 18 句字幕，平均 1.42s/句，排比段压到 1.1s 加速
- 左上角「图片由AI生成 无不良引导」（合规标识，必须有）
- 适合：单句金句、一段引文

### 形态 B · 图集（禾泽日记）

- 1150×2048（≈9:16），13–14 张
- **封面（第 1 张）左上角压人名 + 钩子，内页（2–N）纯图无字**
- 画面：AI 生成，统一风格（罗素=黑白胶片，苏格拉底=暖调写实）
- 适合：人物传记、历史故事。手动滑，节奏由用户控制

### 形态 C · 长轮播（每天读书）

- 720×1280（9:16），7–12 分钟，14–25 张，29s/图
- **固定模板**：顶部深色标题条（黄字）+ 底部深色装饰带 + 白色小字幕 + 右下角水印
- 只换中间的图，框架不动
- 适合：讲书、深度解读

### 形态 D · 书单情绪（晚禾书语）

- 576×768（3:4），40–53s，7–10 张，5–7s/图
- 三段结构：**钩子卡（纯文字）→ 书封过渡卡 → 场景图 ×N**
- 顶部固定书名条：《中国人的家风》余世存·著
- **中英双语字幕**，2.5s 一句
- 画面：AI 生成的家庭/生活场景，写实但柔焦
- 适合：金句+书单，短视频引流

### 形态 E · 影视解说（麦麦陪你读书）

- 576×768（3:4，上下有黑边），8 分 23 秒
- 中间是**真人视频片段**（影视/采访素材），不是图
- 顶部黑边白色大字标题，底部黑边白色字幕
- 15–20s 一段，靠剪辑推进
- 适合：有片源的长解说。你没片源，这条跳过

## 五、图集可以直接抓原图

`wx-downloader` 遇到图集直接报「暂不支持」，但元宝接口返回了完整图片直链（`feedInfo.picInfo`，mediaType=2）。`wx_fetch.py` 把它接了出来：

```bash
E:/AIProject/erchuang/.venv/Scripts/python.exe wx_fetch.py <链接...> -o 对标
```

图集 → `images/01.jpg…`，**1150×2048 原图，450–600KB**，无压缩损失。

## 六、画幅不统一，别只做 9:16

| 画幅                         | 谁在用         |
| -------------------------- | ----------- |
| 9:16（720×1280 / 1150×2048） | 每天读书、禾泽日记   |
| 2:3（1080×1624）             | 叔本华         |
| 3:4（576×768）               | 晚禾书语、麦麦陪你读书 |

3:4 那组集中在书单号。这不是随手选的——3:4 在信息流里占的高度更小，滑动手感更轻，适合"快速翻看"的内容。

你现在 erchuang 写死 1080×1920。如果要试 3:4，得改 `config.py` 的 width/height，而且 `zoompan` 的 `scale` 参数也要跟着改。

## 七、给你的选择

你的四个题材，对应最省力的形态：

| 题材      | 推荐形态         | 理由                          |
| ------- | ------------ | --------------------------- |
| 人物传记    | **B 图集**     | 13–14 张 AI 黑白照片，封面压人名，零配音成本 |
| 大美中国/名校 | **B 图集** 或 C | 真实照片，图集天然适合风景               |
| 传统文化    | **D 书单情绪**   | 钩子卡 + 场景图，40 秒讲完一个点         |
| 历史故事    | **A 单图** 或 B | 一张油画撑 30 秒，成本最低             |

图集是你现在最该做的——不用配音、不用字幕、不用渲染，13 张图 + 一个封面文案就能发。而配音和渲染恰恰是你整条链路里最慢的环节。
